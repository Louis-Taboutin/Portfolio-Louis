IVAR - Systematic Value Premium Strategy

Modèle d'investissement quantitatif long-only sur le Top 500 US Large Caps, corrigeant trois biais académiques de la value passive : ajustement du Book-to-Market par le capital intangible (méthode Eisfeldt, Kim & Papanikolaou, perpetual inventory du SG&A, δ = 0,20), tri de la value within-industry, et signal composite value/quality/momentum (50/25/25) intégrant le F-Score de Piotroski et les indicateurs de qualité AQR pour limiter les « value traps ». Backtesté sur 2000–2024 avec séparation in-sample (2000–2012) / out-of-sample (2013–2024), régression Fama-French 5 facteurs + momentum, tests de robustesse et t-test de significativité (Newey-West HAC).

# IVAR — Intangible Value with Applied Risk Filters
def form_int_value_enhanced(df):
    x = df.copy()

    # 1. Filtres anti-trap (Piotroski 2000, Cooper et al. 2008)
    x = x[(x["roa"] >= MIN_ROA) &                    # ROA >= 5% : profitabilite minimale
           (x["gross_profit"] >= MIN_GP) &            # GP/A >= 5% : qualite operationnelle
           (x["asset_growth"] <= MAX_AG)].copy()      # AG <= 30% : exclut expansions agressives

    # 2. Score composite : 50% value + 25% quality + 25% momentum
    x["composite"] = (W_VALUE*x["value_z"].fillna(0) +
                      W_QUALITY*x["quality_z"].fillna(0) +
                      W_MOM*x["mom_z"].fillna(0))

    # 3. Overweight tilt autour du cap-weighted
    x["score_pct"] = x.groupby("rebal_date")["composite"].rank(pct=True)
    total_mc = x.groupby("rebal_date")["mktcap"].transform("sum")
    x["base_weight"] = x["mktcap"]/total_mc
    x["multiplier"] = (1.0+OW_STRENGTH*(2.0*(x["score_pct"]-0.5)))\
        .clip(lower=0.05)
    x["raw_weight"] = x["base_weight"]*x["multiplier"]

    # 4. Plafonnement iteratif a MAX_WEIGHT (5%)
    return cap_weights(x)
